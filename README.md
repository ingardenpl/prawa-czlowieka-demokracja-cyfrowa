# Prawa człowieka w demokracji cyfrowej

**Neurodane, sztuczna inteligencja i nowe granice prawa do prywatności**

Wykład gościnny online dla ELSA Lublin, 25 listopada 2026 r. Interaktywna prezentacja w formie wędrówki po mapie Aten: od Pireusu do Areopagu, dziewięć przystanków.

**Prezentacja:** https://ingardenpl.github.io/prawa-czlowieka-demokracja-cyfrowa/

**Wydarzenie ELSA Lublin:** https://fb.me/e/c2gsUlGtJ

Autor: dr Karol Kasprowicz, Wydział Prawa i Administracji UMCS.

## Jak oglądać

Prezentacja działa w przeglądarce, bez instalacji i bez łączenia się z zewnętrznymi serwerami.

| Klawisz | Działanie |
|---|---|
| strzałki, spacja | następny lub poprzedni krok |
| G | spis slajdów (także dodatek) |
| S | źródła |
| N | notatki do slajdu |
| Y | zmiana stylu (grecki lub styl silnika) |
| E | wędrówka po mapie |
| H | pomoc ze wszystkimi skrótami |

Głosowania z wykładu działają tu jako pytania dla czytelnika. Głosowanie z telefonów było dostępne tylko na żywo.
